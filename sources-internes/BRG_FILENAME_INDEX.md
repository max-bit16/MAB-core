## Recommandation

Ne pas renommer les fichiers originaux tant que des documents MAB ou scripts peuvent pointer vers leurs noms actuels. La meilleure solution operationnelle est :

1. Conserver les fichiers BRG avec leurs noms d'origine.
2. Utiliser cet index comme source de verite.
3. Copier dans `sources-internes/OneDrive_1_16-06-2026/` les pays cibles manquants si le workflow local ne lit que ce dossier.
4. Si un renommage est souhaite plus tard, creer des copies avec un prefixe lisible, par exemple `BRG_Portugal_PT_Bathrooms_Full_Report_Sep18.pdf`, en conservant les originaux.
